# おかねナビ

自分専用の家計簿・資産管理アプリ（iPhone向けPWA）。
銀行・クレジットカード・PayPay・証券・ポイント／マイルのお金の動きを1か所にまとめ、給料や積立を踏まえた将来の見通しまで確認できます。

**データはすべてiPhoneの中（Safari の IndexedDB）にだけ保存され、外部には送信されません。**

## 機能

- **ホーム**：純資産（預金・投資・ポイント・カード未払い）と推移、今月の収支、月末の見込み、予算の進み具合、カード引き落とし・固定費の予定、ポイント失効のお知らせ
- **明細**：月ごとの一覧、検索、口座・分類での絞り込み、手入力、編集（分類を直すと同じお店にも適用され、ルールとして学習）
- **取り込み**
  - PayPay アプリの取引履歴 CSV（自動で判別）。チャージ・送金・受け取り・ポイント獲得・返金を判別し、カード払いやポイント払いの行は取り込み先を選べる
  - 銀行・カード・証券の CSV（Shift_JIS/UTF-8 自動判別、列は自動推定＋手動で修正可、口座ごとに設定を記憶）
  - 同じ明細を何度取り込んでも重複しない
- **自動分類**：コンビニ・スーパー・サブスク・通信・光熱費・給与・カード引き落とし・PayPayチャージ・証券積立など約150の標準ルール。チャージやカード払いは「振替」として収支から除外
- **分析**：カテゴリ別（前月との差）、12か月の収支推移・貯蓄率、資産推移、固定費・サブスクの自動検出、よく使ったお店
- **将来**：手取り・賞与・生活費・積立・利回り・昇給率から最大50年の資産推移を計算。1000万・3000万などに届く時期、預金が足りなくなる時期、「年間生活費÷4%」の目安、引っ越しなど大きなイベント
- **口座**：銀行・PayPay・現金（残高合わせ）、カード（締め日・引き落とし日から未払い額を計算）、証券（評価額・元本を記録）、ポイント・マイル（換算レート、失効日）
- **バックアップ**：JSON で保存・復元、取引を CSV で書き出し。オフラインでも動きます

## iPhoneへの入れ方

1. Safari で公開URL（GitHub Pages）を開く
2. 共有ボタン → 「ホーム画面に追加」
3. ホーム画面のアイコンから起動

## 開発

```sh
npm start   # http://localhost:8080
npm test    # 取り込み・集計ロジックのテスト
```

ビルドは不要です（素の HTML/CSS/JavaScript）。
